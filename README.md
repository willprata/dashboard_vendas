# 📊 Dashboard de Vendas

Dashboard interativo desenvolvido em **Python + Streamlit** para análise de vendas, permitindo visualizar indicadores, evolução da receita e desempenho por categoria.

O projeto foi desenvolvido como atividade prática de **Business Intelligence e desenvolvimento de dashboards interativos**.

🔗 **Dashboard online:**

---

## 📌 Sobre o Projeto

O objetivo deste projeto é transformar dados de vendas em informações visuais e interativas, facilitando a análise do desempenho comercial.

O dashboard permite explorar os dados por meio de filtros e indicadores, apresentando as principais informações de forma simples e organizada.

---

## 📈 Principais Indicadores

O dashboard apresenta os seguintes indicadores:

- 💰 **Receita Total**
- 🛒 **Total de Pedidos**
- 📦 **Quantidade Vendida**
- 🎟️ **Ticket Médio**

Além dos indicadores, também são apresentados gráficos para análise dos dados.

---

## 🎯 Funcionalidades

### 🔎 Filtros

O usuário pode utilizar filtros para analisar os dados de acordo com:

- Categorias de produtos
- Gênero
- Período

Os indicadores e gráficos são atualizados de acordo com os filtros selecionados.

### 📊 Gráficos

O dashboard apresenta:

- Evolução mensal da receita
- Receita por categoria
- Desempenho das vendas

### 📋 Dados das Vendas

Também é possível visualizar os registros utilizados no dashboard em uma tabela.

O projeto possui ainda a opção de baixar os dados filtrados em formato **CSV**.
